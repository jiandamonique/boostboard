Boost Board Is Ready to Grow

Volunteer Team · 2026-10-03

When we launched Boost Board, we built it on GitHub Pages. That was the right call. GitHub Pages is free, stable, and fast — it let us figure out what this platform needed to be before spending a dollar on infrastructure.

We figured it out. Over the past few months, we've added 44 active campaigns, a tier system that surfaces who needs the most attention, a daily email spotlight, weekly digests, an RSS feed, category filtering, a campaign archive, and a public API that community builders can pull from. All of that is working, and it's working well.

But GitHub Pages is a static host. It doesn't run code. And there are things Boost Board needs to do that require code to run on a server — a real one, with a real domain name.

What we can't do from here

Right now, unsubscribe links work because we have a workaround that involves a credential stored directly in the page. It works, but it's not a long-term solution. A proper server handles that cleanly, with no exposure.

A custom domain matters beyond just optics. When a journalist covers a campaign, the link in their article needs to be permanent and ours. When a campaign organizer shares the Boost Board listing with their network, the URL needs to be one they trust. jiandamonique.github.io/boostboard does the job right now, but it ties the platform's credibility to a personal account subdomain.

Email automation, moderation tools, and the daily spotlight logic all currently depend on scripts that have to be run manually. Giving those a proper home means the board keeps moving even when the volunteer team is stretched thin — which, honestly, is most of the time.

What moving looks like

We've already done the hard part. The platform is built. The data model is solid. The design is working. What migration means is: a domain name, a year or two of hosting, and some setup time to wire everything together in its new home.

We're not rebuilding from scratch. We're lifting what exists and setting it down somewhere it can breathe.

The lean cost for that is around $900 to start — domain registration, hosting, and the setup work to get everything stable. After that, keeping it running is around $85 a year. We've kept costs this low by doing everything ourselves, and we intend to keep it that way.
