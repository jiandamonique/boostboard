How Fundraisers Get Found

Volunteer Team · 2026-09-07

We spend a lot of time here thinking about visibility, so it's worth laying out the real ways someone finds a fundraising page — and where each of those paths quietly breaks down for a brand-new campaign.

Searching on the platform itself

GoFundMe's own search looks for the creator's name or the campaign title, and it also supports a "fundraisers near you" location filter — a genuinely useful, native way to browse what's happening nearby. The catch: search tends to favor campaigns that are already active and already getting engagement. A page that's real, public, and only a day old can sit well below campaigns that simply started earlier and picked up some early traction.

External search engines

Public campaigns are indexed by Google and similar engines, so a search combining a person's name with the platform (or a site-specific search) can sometimes surface a page the platform's own search didn't. This depends entirely on the page having been crawled and indexed already, which takes time a brand-new campaign hasn't had yet.

Social media as the real bridge

In practice, a lot of discovery doesn't happen through search at all — it happens because someone shared the link. A bio update, a single post, a link in a story. This works well for people with an existing audience to share to, and works far less well for someone without one, which is exactly the gap this project is trying to help with.

Privacy settings matter more than people expect

Not every campaign is meant to be found by a stranger. GoFundMe supports fully Public pages, Private pages (link-only), and Friends & Family pages (visible only to an approved network). If a page isn't turning up anywhere, it may simply be set that way on purpose — and the respectful move is to ask the person directly for the link, not to go looking for a workaround.

Why this all matters here

Every one of these paths rewards a campaign that's already got some momentum, a network to share into, or time to be indexed. A completely new, completely public, completely legitimate page can still be functionally invisible for a while — not because anything is wrong with it, but because none of these ordinary discovery paths are built for day one. That's the gap this board exists to help with.
